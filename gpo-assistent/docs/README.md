# SchoolRecht Documentatie

Hier vind je alle informatie over de architectuur, de API-specificaties en de zoekevaluatie.

## Inhoudsopgave

1. **[Architectuur & Technisch Ontwerp](architecture.md)**
   Overzicht van de frontend (React + NL Design System), backend (FastAPI), opslagarchitectuur (PostgreSQL), cryptografische bronverificatie (SHA-256) en het hybride retrieval-systeem.

2. **[REST API Specificatie](api.md)**
   Gedetailleerde referentie van alle openbare API-endpoints, request/response schema's en voorbeelden.

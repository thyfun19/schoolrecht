# Publiceerbare bronregistratie

`catalogus.json` bevat de selectie van tien openbare GPO-adviezen als verwijzingen en technische controlemetadata. Geen inhoudelijke bronpassages of persoonlijke leerlinggegevens.

De originele PDF’s, geëxtraheerde tekst en SQLite-database blijven lokaal. Publiceer geen broncorpus zolang de voorwaarden voor het beoogde hergebruik niet voldoende zijn verduidelijkt. De toekomstige import controleert het lokale bestand tegen de vastgelegde hash en paginatelling.
